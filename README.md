# 高宏教育 · 辅立码课操作手册

面向高宏教育教师与学生使用的**离线+在线双用**辅立码课操作手册站点：左侧场景导航，右侧「适用场景 → 操作步骤 → 指标口径 → 配套视频 → 手册原文与截图」五段式内容。

- 在线访问：GitHub Pages（启用后为 `https://<用户名>.github.io/<仓库名>/`）
- 离线使用：整个文件夹拷到 U 盘或平板，双击 `index.html` 即可，视频与截图全部走相对路径。

## 维护方式

1. **改文字/加条目**：只改 `index.html` 里的 `DATA`（条目清单）和 `MANUAL`（手册原文与截图映射）两个 JS 对象，页面渲染无需改动。
2. **加视频**：把 mp4 放进对应场景目录，在 `DATA` 里给该条目补 `video` 字段（相对路径，中文需 `encodeURI`）。
3. **加手册截图**：图片放入场景目录的 `手册/` 下，在 `MANUAL` 对应条目里补 `{src, cap}`。
